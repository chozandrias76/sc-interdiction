Add visual highlighting for Wikelo source locations on the map canvas.

1. In render_system_canvas(), when drawing location circles:
   - Check if `loc.wikelo_items.is_empty()` is false (is a Wikelo source)
   - If Wikelo source: Draw outer ring in Magenta (high_value) or LightMagenta (regular)
   - The outer ring should be slightly larger than the location circle
   - Keep original location circle inside (Planet=Cyan, etc.)

2. Implementation pattern (after drawing location circle):
   ```rust
   if !loc.wikelo_items.is_empty() {
       let ring_color = if loc.wikelo_high_value {
           Color::Magenta
       } else {
           Color::LightMagenta
       };
       // Draw ring as circle segments (like orbit rings)
       let ring_radius = radius + 0.8;
       let segments = 16;
       for i in 0..segments {
           let a1 = 2.0 * std::f64::consts::PI * i as f64 / segments as f64;
           let a2 = 2.0 * std::f64::consts::PI * (i + 1) as f64 / segments as f64;
           ctx.draw(&CanvasLine {
               x1: x + ring_radius * a1.cos(),
               y1: y + ring_radius * a1.sin(),
               x2: x + ring_radius * a2.cos(),
               y2: y + ring_radius * a2.sin(),
               color: ring_color,
           });
       }
   }
   ```

3. Add legend hint to title_bottom: "◎:Wikelo" after existing hints

Do NOT implement filter toggle yet - just highlighting. Filter is Task 3.
  </action>
