  <name>Task 2: Enhance hotspot details with Wikelo breakdown</name>
  <files>crates/cli/src/tui/views/map.rs</files>
  <action>
Add Wikelo item breakdown to hotspot detail panel (both compact and expanded views).

1. In render_hotspot_details_compact():
   After the "Jump to" / "Exit at" / "Lateral" section, add Wikelo section:

   ```rust
   // Wikelo intel section (if hotspot has Wikelo data)
   // Note: RouteIntersection doesn't have wikelo fields directly
   // We need to check if the hotspot location is a Wikelo source using WikieloIntel
   // This was partially set up in 05-02, extend it here

   // If hotspot has any intersecting routes with wikelo_items:
   let all_wikelo_items: Vec<_> = hotspot.intersecting_routes
       .iter()
       .flat_map(|r| r.wikelo_items.iter().cloned()) // Need to add this field
       .collect::<std::collections::HashSet<_>>()
       .into_iter()
       .take(5)
       .collect();

   if !all_wikelo_items.is_empty() {
       info_text.push(Line::from(""));
       info_text.push(Line::from(vec![
           Span::styled("Wikelo Items: ", Style::default().fg(Color::Magenta).add_modifier(Modifier::BOLD)),
       ]));
       for item in &all_wikelo_items {
           info_text.push(Line::from(vec![
               Span::raw("  • "),
               Span::styled(item, Style::default().fg(Color::LightMagenta)),
           ]));
       }
   }
   ```

2. Actually, RouteIntersection.intersecting_routes are IntersectingRoute structs.
   Check if IntersectingRoute has origin field - if so, use WikieloIntel to look up items.

   Simpler approach: The hotspot's `name` field contains the location name.
   Use WikieloIntel.items_at(hotspot_name) to get items.

   This requires passing WikieloIntel to the render function.
   - Option A: Add to App and pass reference
   - Option B: Store pre-computed Wikelo data in RouteIntersection

   Since 05-02 already adds WikieloIntel to App, use that:
   - Add `wikelo_intel: &WikieloIntel` parameter to render_hotspot_details functions
   - Call from render_map with `&app.wikelo_intel`

3. Update render_hotspot_details_expanded() similarly - add Wikelo section in the summary area.

4. Consider increasing compact panel height from 12 to 14 lines to fit Wikelo section.

Keep formatting consistent with existing panel style.
