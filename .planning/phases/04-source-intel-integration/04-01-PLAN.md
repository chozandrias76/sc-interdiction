<task type="auto">
  <name>Task 2: Add source flagging methods to WikieloIntel</name>
  <files>crates/intel/src/wikelo/intel.rs</files>
  <action>
Add analysis methods to WikieloIntel:

1. `is_wikelo_source(&self, location: &str) -> bool`
   - Returns true if location has any Wikelo items
   - Uses WikieloRegistry::items_at_location()

2. `items_at(&self, location: &str) -> Vec<&WikieloItem>`
   - Wrapper around registry.items_at_location()
   - Returns items available at this location

3. `flag_location(&self, location: &str) -> Option<SourceFlag>`
   - Returns a SourceFlag struct with:
     - location: String
     - item_count: usize
     - top_items: Vec<WikieloItemSummary> (name, category, estimated_value)
     - has_high_value: bool (any item with estimated_value > 10000)
   - Returns None if location has no Wikelo items

4. `flag_system(&self, system: &str) -> Option<SystemFlag>`
   - Similar to flag_location but aggregates across all locations in system
   - Includes location_count field

Create SourceFlag and SystemFlag structs with Serialize derive.
Create WikieloItemSummary struct (subset of WikieloItem for display).
  </action>
  <verify>cargo check -p intel compiles, cargo test -p intel runs existing tests</verify>
  <done>WikieloIntel has is_wikelo_source, items_at, flag_location, flag_system methods</done>
