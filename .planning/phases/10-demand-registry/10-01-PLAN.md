  <name>Task 1: Create ContractRegistry with bidirectional indexes</name>
  <files>crates/intel/src/wikelo/contract_registry.rs, crates/intel/src/wikelo/mod.rs</files>
  <action>
Create `contract_registry.rs` following WikieloRegistry pattern exactly:

**Struct:**
```
ContractRegistry {
    contracts: Vec<WikieloContract>,
    by_id: HashMap<String, usize>,
    by_category: HashMap<ContractCategory, Vec<usize>>,
    by_item: HashMap<String, Vec<usize>>,        // item_id → contract indexes
    by_location: HashMap<String, Vec<usize>>,     // turn-in location → contract indexes
    by_confidence: HashMap<DataConfidence, Vec<usize>>,
}
```

**Constructors:**
- `new()` → calls `Self::from_contracts(all_contracts())`
- `from_contracts(contracts: Vec<WikieloContract>)` → builds all indexes

**Index building in from_contracts:**
- `by_id`: contract.id → index
- `by_category`: contract.category → index
- `by_item`: iterate contract.requirements, each requirement.item_id → index (this is the critical bidirectional link)
- `by_location`: iterate contract.turn_in_locations, normalize_location each → index
- `by_confidence`: contract.confidence → index

**Query methods (all #[must_use], return references):**
- `get(id: &str) -> Option<&WikieloContract>`
- `all_contracts() -> &[WikieloContract]`
- `by_category(cat: ContractCategory) -> Vec<&WikieloContract>`
- `contracts_requiring_item(item_id: &str) -> Vec<&WikieloContract>` — the key demand lookup
- `contracts_at_location(location: &str) -> Vec<&WikieloContract>` — uses normalize_location
- `by_confidence(conf: DataConfidence) -> Vec<&WikieloContract>`
- `contract_count() -> usize`
- `all_required_items() -> Vec<&str>` — unique item IDs across all contracts
- `high_confidence() -> Vec<&WikieloContract>` — confidence >= Confirmed
- `needs_validation() -> Vec<&WikieloContract>` — confidence <= Partial

**Traits:** Clone, Default (calls new())

Reuse `normalize_location` from registry.rs — make it `pub(super)` if currently private, or duplicate if simpler.

**Do NOT** add any methods not listed above. Keep it minimal — Phase 11 will add demand-specific queries if needed.

Update mod.rs: add `mod contract_registry;` and `pub use contract_registry::ContractRegistry;`
