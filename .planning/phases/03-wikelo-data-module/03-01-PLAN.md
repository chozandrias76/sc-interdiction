   - `by_system: HashMap<String, Vec<usize>>` - System to item indexes
   - `by_category: HashMap<ItemCategory, Vec<usize>>` - Category to item indexes
   - `from_items(items: Vec<WikieloItem>) -> Self` - Build indexes from items

Add lookup methods to WikieloRegistry following ShipRegistry pattern:

**Item lookups:**
- `get(&self, id: &str) -> Option<&WikieloItem>` - Get item by ID
- `all_items(&self) -> &[WikieloItem]` - Get all items

**Location lookups:**
- `items_at_location(&self, location: &str) -> Vec<&WikieloItem>` - All items at a location
- `items_in_system(&self, system: &str) -> Vec<&WikieloItem>` - All items in a system

**Category lookups:**
- `items_by_category(&self, category: ItemCategory) -> Vec<&WikieloItem>` - All items in category

**Utility:**
- `all_locations(&self) -> Vec<&str>` - List all unique location names
- `all_systems(&self) -> Vec<&str>` - List all unique systems
- `item_count(&self) -> usize` - Total items in registry

Follow ShipRegistry's normalize_ship_name pattern for location matching (lowercase, collapse whitespace).
