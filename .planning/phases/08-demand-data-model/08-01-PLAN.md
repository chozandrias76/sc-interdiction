Add the following types to contracts.rs (above existing types, after imports):

1. **ContractCategory** enum — categorizes contracts for filtering:
   - Prerequisite, FavorExchange, Weapon, Armor, Ship, Equipment
   - Derive: Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize
   - Doc comments on each variant explaining what it means

2. **DataConfidence** enum — tracks how reliable contract data is:
   - Inferred = 1 (from name only), Partial = 2, Confirmed = 3, Verified = 4, Authoritative = 5
   - Derive: Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize
   - Use repr(u8) for numeric comparison
   - Doc comments explaining each level

3. **CurrencyType** enum — models the different currencies in the economy:
   - Auec, MgScrip, CouncilScrip, WikieloFavor, PolarisBit, Carinite, Other(String)
   - Derive: Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize
   - This replaces hardcoded string-based currency references

4. **ExchangeRate** struct — models a currency conversion:
   - input_currency: CurrencyType
   - input_quantity: u32
   - output_currency: CurrencyType
   - output_quantity: u32
   - Derive: Debug, Clone, Serialize, Deserialize
   - Add method `rate(&self) -> f64` returning output_quantity / input_quantity as f64

Do NOT modify existing types in this task. Keep the new types self-contained.
