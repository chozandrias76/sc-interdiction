<task type="auto">
  <name>Task 1: Add Item subcommand to CLI</name>
  <files>crates/cli/src/main.rs</files>
  <action>
Add `Item` variant to Commands enum with:
- `query: String` - Item name or partial match
- `--json` flag for JSON output

Add `handle_item()` function that:
1. Creates WikieloIntel::from_static()
2. Searches all items for matches (case-insensitive substring on item.name)
3. For each matching item, collect:
   - Item name, category, estimated_value
   - Source locations (from item.sources)
   - Contracts requiring it (via contracts().contracts_requiring_item(&item.id))
4. If `--json`, output JSON. Otherwise, print formatted table/details.

Table format for non-JSON:
```
Item: Irradiated Valakkar Fang
Category: CreaturePart, Value: ~75,000 aUEC

Sources:
  • Lazarus Transport Centers (Pyro)
  • Daymar (Stanton)

Used in Contracts:
  • Valakkar Trophies (turn-in: Wikelo Emporium Dasi)
  • Pyro Hunter (turn-in: Wikelo Emporium Kinga)
```

Match existing CLI patterns - follow handle_ships(), handle_intel() for structure.
  </action>
  <verify>

  </verify>
